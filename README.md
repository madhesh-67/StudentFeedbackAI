# StudentFeedbackAI

AI-Based Student Feedback Sentiment, Emotion & Aspect Analyzer.

## Features
- Single feedback analysis
- Batch CSV analysis
- Sentiment, emotion and multiple aspect detection
- Interactive dashboard
- Hybrid CNN + Bidirectional LSTM + NLP rules

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment
Designed for Streamlit-compatible hosting such as Render using `render.yaml`.
